## whiteboard-app 
whiteboard app is an interactive drawing application developed using HTML,CSS and Javascript. 
The application alows users to draw freely on a digital canvas with smooth brush strokes and responsive controls. 

## Project Overview 
This project demonstrates the use of the HTML5 Canvas API and Javascript event handling to implement real time drawing functionality.
The application is desingned with a clean and user friendly interface. 

## key Fetures   
  freehand drawing using mouse events  
  
  Smooth brush strokes  
  
  Clear canvas functionality
  
  Responsive layout
  
  Organized and modular code structure 

## Technologies Used
   HTML
   
   CSS
   
   JAVASCRIPT (ES6)
   
   CANVAS API

## Concepts Applied
  DOM Manipulation
  
  Event Listeners
  
  Canvas Rendering Context 
  
  Mouse Event Handling
  
  Responsive UI Design
